## [0.1.0] - 2026-11-09

### Added

- Six-section layout with floating navbar and section rail.
- English and Portuguese with a typed dictionary.
- Live age counter in the Sao Paulo time zone.
- Interactive dot portrait generated at build time.
- Three.js liquid blobs with a CSS fallback.
- Project cards from the GitHub API with a fallback list.
- Guestbook with D1, Turnstile, honeypot and an hourly limit per visitor.
- Copy email button, SEO metadata, custom 404 page and security headers.
- CI, secret scanning, Dependabot and commit hooks.
